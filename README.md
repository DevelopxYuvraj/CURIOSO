# 🇮🇳 CURIOSO — Learn India Through Play

### ✨ Explore. Learn. Play. Celebrate India.

**CURIOSO** is an interactive cultural learning platform designed to make exploring India's rich heritage, traditions, festivals, art forms, and history fun and engaging. By combining technology with cultural education, CURIOSO offers a digital journey through the incredible diversity of India.

Our mission is to make Indian culture more accessible to everyone through interactive learning, engaging quizzes, beautiful visuals, and an immersive user experience.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/DevelopxYuvraj/CURIOSO.git
```

### 2. Navigate to the project folder

```bash
cd CURIOSO
```

### 3. Open the project

Open the folder in Visual Studio Code.

If the project has a Node.js backend, install its dependencies from the directory containing `package.json`:

```bash
npm install
```

### 4. Run the website

Open `index.html` in your browser, or use the **Live Server** extension in VS Code if the project is configured as a static website.

For a Node.js backend, follow the startup command configured in `package.json`.
